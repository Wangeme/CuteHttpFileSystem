原始机器可读结果见 `artifacts/performance.json`。回环测试可证明应用层没有明显低速串行瓶颈，

客户端浏览器组合上复测。

本轮优化前同机上传基线为 207.95 MiB/s。加入断线竞态保护后的三次结果为 235.87、
224.42、236.51 MiB/s，中位数提升约 13.4%。浏览器端进度刷新同时限制为约 10 FPS；该收益需继续用真实
手机和 Wi-Fi 链路复测。

## 4. 质量结论与剩余边界

- 大文件和完整 128 MiB 分块均不会整体聚合到服务端应用缓冲；峰值主要由 ASGI 网络小块、
  浏览器分块以及协议缓冲决定。
- 快速模式省略浏览器逐块 SHA-256；严格客户端仍可提交摘要，错误摘要不会推进服务端偏移。
- 只有总长度满足、`fsync` 完成后才原子发布目标文件；服务端全程流式计算整文件 SHA-256。
- 桌面浏览器主流程、390 × 844 移动视口和原生桌面“运行概览”中的共享文本面板均已做真实界面验证；四按钮、跨端读取、自动保存及自动刷新通过。
- v0.1.0 wheel 构建成功，并核对安装包包含全部 Python 模块与四个浏览器资源文件。
