# CHFS v0.3.3

本次正式 Release 补齐了 `v0.3.2` 之后已经进入 `main`、但尚未上传到 Release 页面的功能。

## 主要变化

- 手机和电脑浏览器可以直接下载文件夹或多个选中项目。
- 服务端使用 ZIP64 边读取边输出，避免先在磁盘生成一个同等大小的临时压缩包。
- 桌面端可按需隐藏本机地址，减少不需要的信息展示。
- Windows 构建脚本现在自动生成 `SHA256SUMS.txt`，便于核对下载附件。
- 整理正式发布流程，消除“源码已更新、Release 仍停留在旧版本”的隐患。

## 验证

- 68 项自动化测试通过，2 项按当前环境跳过。
- 桌面 EXE 由仓库内 `scripts\build_exe.cmd` 构建。
- 请同时下载 `CHFS.exe` 与 `SHA256SUMS.txt` 并核对 SHA-256。

当前 Windows 程序尚未进行商业代码签名。若 SmartScreen 或 Defender 发出提示，请不要关闭安全软件；参见 [Windows 下载与安全校验](../10-windows-download-security.md)。
