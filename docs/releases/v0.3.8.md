# CHFS v0.3.8

本版本让桌面概览页的“最近操作”可以直接操作对应的本地文件。

## 主要变化

- 双击带文件路径的最近操作记录，直接使用系统默认应用打开首个目标。
- 右键文件记录可选择“打开”“复制路径”“在文件资源管理器中打开”。
- 多路径记录会把全部本地路径复制到剪贴板；复制和移动记录优先定位操作后的目标。
- 已不存在的文件会给出明确提示，资源管理器操作会尽量打开仍存在的父目录。
- 共享目录和“此电脑”路径重新经过安全解析，损坏或被篡改的日志不能借此越界打开路径。

## 验证

- 78 项自动化测试通过，3 项因当前测试 Python 缺少可用 Tk 运行时而跳过；Python `compileall` 检查通过。
- Windows 程序由仓库内 `scripts\build_exe.cmd` 在本地构建。
- Release 同时提供 `CHFS.exe` 与 `SHA256SUMS.txt`，请在运行前核对 SHA-256。

当前 Windows 程序尚未进行商业代码签名。若 SmartScreen 或 Defender 发出提示，请不要关闭安全软件；参见 [Windows 下载与安全校验](https://github.com/Wangeme/CuteHttpFileSystem/blob/main/docs/10-windows-download-security.md)。
