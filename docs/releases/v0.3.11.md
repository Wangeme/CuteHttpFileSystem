# CHFS v0.3.11

本版本允许在桌面运行概览中直接修改监听端口。

## 主要变化

- “服务概览”卡片中的监听端口由只读文字改为紧凑输入框。
- 输入新端口后自动校验并原子保存配置，无需切换到“网络与访问”页面。
- 服务运行期间修改端口时，继续使用既有安全重启状态机自动应用最新配置。
- “网络与访问”页仍保留完整的监听地址、端口和来源网段设置。
- 增加 GUI 回归测试，验证概览端口输入与共享配置变量绑定并能持久化。

## 验证

- 81 项自动化测试、Python `compileall` 与 JavaScript 语法检查通过。
- 完成 1120 × 720 桌面概览视觉验收，端口输入框未破坏现有布局。
- Windows 程序由仓库内 `scripts\build_exe.cmd` 在本地构建。
- Release 同时提供 `CHFS.exe` 与 `SHA256SUMS.txt`，请在运行前核对 SHA-256。

当前 Windows 程序尚未进行商业代码签名。若 SmartScreen 或 Defender 发出提示，请不要关闭安全软件；参见 [Windows 下载与安全校验](https://github.com/Wangeme/CuteHttpFileSystem/blob/main/docs/10-windows-download-security.md)。
