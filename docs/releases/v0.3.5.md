# CHFS v0.3.5

本版本把审计日志表升级为接近 Windows 文件资源管理器“详细信息”视图的列操作体验。

## 主要变化

- 调整时间、用户、操作、IP、MAC 和结果列的默认宽度与对齐方式。
- 可拖动列边界改变宽度，也可拖动表头调整列顺序。
- 双击表头切换该列的升序或降序；双击列边界按当前内容自动调整宽度。
- 右键表头可隐藏或恢复任意列，并提供“显示所有列”和“恢复默认布局”。
- 页面切换期间保留当前列宽、顺序与可见状态，程序重新启动时使用整齐的默认布局。

## 验证

- 72 项自动化测试通过，2 项因当前测试运行时缺少 Tk 图形组件而跳过。
- 自动化测试覆盖日志内容格式和隐藏列条件下的列顺序合并。
- 使用真实 Tk 控件验证隐藏列、恢复列和默认布局操作。
- Windows 程序由仓库内 `scripts\build_exe.cmd` 在本地构建。
- Release 同时提供 `CHFS.exe` 与 `SHA256SUMS.txt`，请在运行前核对 SHA-256。

当前 Windows 程序尚未进行商业代码签名。若 SmartScreen 或 Defender 发出提示，请不要关闭安全软件；参见 [Windows 下载与安全校验](https://github.com/Wangeme/CuteHttpFileSystem/blob/main/docs/10-windows-download-security.md)。
